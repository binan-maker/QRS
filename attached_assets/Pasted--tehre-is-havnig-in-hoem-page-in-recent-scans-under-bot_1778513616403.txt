## 🔍 Root Cause Analysis

| Symptom | Technical Reason | Cost/Perf Impact |
|---------|------------------|------------------|
| **Simultaneous loads on Home + Profile** | Each screen fetches `avatarUrl` independently | 2x Storage reads + bandwidth per navigation |
| **No cache invalidation** | URL stays same → browser/OS cache serves stale image | User sees old photo until cache expires (hours/days) |
| **High Firestore/Storage bills** | `onSnapshot` or repeated `getDoc` + uncached Storage downloads | ~$8-15/mo wasted on avatar fetches alone |
| **Delayed UI after upload** | Waits for Firestore confirm + Storage URL before updating | 1-3s lag, feels broken |

---

## ✅ Solution Architecture (Zero-Waste + Instant)

```
App Mount → MMKV (sync) → Zustand Store → CachedAvatar (expo-image)
                              ↑
Upload Flow → Optimistic Local URI → Storage Upload → Firestore Update → MMKV + Store Update → Instant UI
                              ↑
Cache Busting → ?v={timestamp} appended to URL → Forces reload ONLY when changed
```

**Key Principles:**
1. **Memory + Disk Cache**: `expo-image` caches aggressively. Zero network calls after first load.
2. **Versioned URLs**: `?v=1717029382` busts cache instantly when user updates photo.
3. **Cross-Screen State**: Zustand shares avatar URL across Home, Profile, Headers, etc.
4. **Optimistic UI**: Shows local file immediately, swaps to CDN URL after upload.
5. **No Real-Time Listeners**: Avatars don't need `onSnapshot`. Sync once on mount + after upload. Saves Firestore reads.

## 📦 Implementation Code

### 1️⃣ Centralized Avatar Store (Zustand + MMKV)
```typescript
// lib/store/avatarStore.ts
import { create } from 'zustand';
import { MMKV } from 'react-native-mmkv';

const storage = new MMKV();
const AVATAR_URL_KEY = 'avatar_url';
const AVATAR_VERSION_KEY = 'avatar_version';

interface AvatarState {
  url: string | null;
  version: number;
  setAvatar: (url: string, version?: number) => void;
  clearAvatar: () => void;
}

export const useAvatarStore = create<AvatarState>((set) => ({
  url: storage.getString(AVATAR_URL_KEY) || null,
  version: Number(storage.getString(AVATAR_VERSION_KEY) || '0'),
  
  setAvatar: (url, version = Date.now()) => {
    storage.set(AVATAR_URL_KEY, url);
    storage.set(AVATAR_VERSION_KEY, String(version));
    set({ url, version });
  },
  
  clearAvatar: () => {
    storage.delete(AVATAR_URL_KEY);
    storage.delete(AVATAR_VERSION_KEY);
    set({ url: null, version: 0 });
  }
}));
```

### 2️⃣ Cached Avatar Component (Drop-in Replacement)
```tsx
// components/ui/CachedAvatar.tsx
import { Image } from 'expo-image';
import { View, Text, StyleSheet } from 'react-native';
import { useAvatarStore } from '@/lib/store/avatarStore';

export function CachedAvatar({ 
  size = 40, 
  fallback = '👤',
  borderRadius 
}: { 
  size?: number; 
  fallback?: string;
  borderRadius?: number;
}) {
  const { url, version } = useAvatarStore();
  const radius = borderRadius ?? size / 2;
  
  // ✅ Cache-bust ONLY when version changes
  const cacheBustedUrl = url ? `${url}?v=${version}` : null;

  return (
    <View style={[styles.container, { width: size, height: size, borderRadius: radius }]}>
      {cacheBustedUrl ? (
        <Image
          source={{ uri: cacheBustedUrl }}
          style={{ width: size, height: size, borderRadius: radius }}
          cachePolicy="memory-disk" // ✅ Aggressive caching
          placeholder={fallback}
          contentFit="cover"
          transition={200}
        />
      ) : (
        <View style={[styles.fallback, { borderRadius: radius }]}>
          <Text style={{ fontSize: size * 0.4 }}>{fallback}</Text>
        </View>
      )}
    </View>
  );
}

const styles = StyleSheet.create({
  container: { backgroundColor: '#f1f5f9', overflow: 'hidden', justifyContent: 'center', alignItems: 'center' },
  fallback: { width: '100%', height: '100%', justifyContent: 'center', alignItems: 'center', backgroundColor: '#e2e8f0' }
});
```

### 3️⃣ Upload Hook with Optimistic UI & Instant Sync
```typescript
// features/profile/hooks/useUpdateAvatar.ts
import { useMutation } from '@tanstack/react-query';
import { doc, updateDoc } from 'firebase/firestore';
import { auth, db } from '@/lib/firebase';
import { useAvatarStore } from '@/lib/store/avatarStore';
import { uploadProfilePhoto } from '@/lib/services/storage-service';

export function useUpdateAvatar() {
  const { setAvatar, url: prevUrl, version: prevVersion } = useAvatarStore();

  return useMutation({
    mutationFn: async (localUri: string) => {
      const result = await uploadProfilePhoto(localUri);
      if (!result.success) throw new Error(result.error || 'Upload failed');
      return result.url;
    },
    
    onMutate: async (localUri) => {
      // ✅ INSTANT UI: Show local file immediately
      const tempVersion = Date.now();
      setAvatar(localUri, tempVersion);
      return { prevUrl, prevVersion };
    },
    
    onSuccess: (downloadUrl) => {
      // ✅ Swap to CDN URL + new version (triggers cache bust)
      const newVersion = Date.now();
      setAvatar(downloadUrl, newVersion);
      
      // Sync to Firestore (1 write, no extra reads)
      if (auth.currentUser) {
        updateDoc(doc(db, 'users', auth.currentUser.uid), {
          avatarUrl: downloadUrl,
          avatarVersion: newVersion
        });
      }
    },
    
    onError: (_, __, context) => {
      // 🔄 Rollback to previous on failure
      if (context?.prevUrl) {
        setAvatar(context.prevUrl, context.prevVersion);
      }
    }
  });
}
```

### 4️⃣ Lightweight Sync on App Start (No Real-Time Listener)
```typescript
// lib/hooks/useSyncAvatarOnMount.ts
import { useEffect } from 'react';
import { doc, getDoc } from 'firebase/firestore';
import { auth, db } from '@/lib/firebase';
import { useAvatarStore } from '@/lib/store/avatarStore';

export function useSyncAvatarOnMount() {
  const { version, setAvatar } = useAvatarStore();

  useEffect(() => {
    if (!auth.currentUser) return;
    
    // ✅ Fetch ONLY on mount. No onSnapshot = zero recurring reads.
    getDoc(doc(db, 'users', auth.currentUser.uid)).then(snap => {
      const data = snap.data();
      if (data?.avatarUrl && data?.avatarVersion !== version) {
        setAvatar(data.avatarUrl, data.avatarVersion);
      }
    }).catch(err => console.warn('Avatar sync failed:', err));
  }, []); // Runs once per session
}
```
**Usage in `app/_layout.tsx`:**
```tsx
export default function RootLayout() {
  useSyncAvatarOnMount(); // ✅ Add this once
  return <Slot />;
}
```

## 🛡️ Edge Cases & Best Practices

| Scenario | Handling |
|----------|----------|
| **User updates photo on another device** | `useSyncAvatarOnMount` catches it on next app open. Add pull-to-refresh on Profile if needed. |
| **Upload fails** | `onError` rolls back to previous URL + version. UI never shows broken state. |
| **Offline mode** | `expo-image` serves disk cache. Fallback emoji if never loaded. |
| **Storage URL changes (migration)** | Version param forces fresh fetch. Old cache auto-evicts. |
| **Multiple avatars (team/business)** | Create `useAvatarStore(uid)` factory or key MMKV by `avatar_${uid}`. |
