# Biggest Loading Delay

I found likely source.

Inside:

```tsx

```

Firestore.

Flow:

```text
Open Home
↓
Query Firestore
↓
Convert results
↓
Cache
↓
Merge local scans
↓
Render
```

This is probably where you feel delay.
