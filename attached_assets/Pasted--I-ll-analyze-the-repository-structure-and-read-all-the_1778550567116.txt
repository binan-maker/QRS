## 🔴 Issue #1: Navigation Bar Becomes White/Invisible in Light Theme

### **Root Cause Analysis**

Looking at **`app/(tabs)/_layout.tsx`** and **`constants/colors.ts`**:

**In `app/(tabs)/_layout.tsx` (ClassicTabLayout):**

```tsx
function ClassicTabLayout() {
  const isWeb = Platform.OS === "web";
  const isIOS = Platform.OS === "ios";
  const insets = useSafeAreaInsets();
  const { colors } = useTheme();
  const { t } = useAppTranslation();

  const tabBarHeight = isWeb ? 84 : 70 + insets.bottom;

  return (
    <Tabs
      screenOptions={{
        headerShown: false,
        tabBarStyle: {
          height: tabBarHeight,
          backgroundColor: colors.surface,  // ← Uses theme surface color
          borderTopWidth: 0,
          elevation: 0,
          shadowOpacity: 0,
        },
        // ... tab bar styling
      }}
    >
```

**In `constants/colors.ts` (Light Theme):**

```ts
const light: AppColors = {
  background: "#F5F8FF",
  surface: "#FFFFFF",        // ← White surface
  surfaceLight: "#EBF1FF",
  surfaceBorder: "#D4E0F5",
  // ...
  tabIconDefault: "#7A99BC",
  tabIconSelected: "#0052CC",
  // ...
  statusBar: "dark",
  blurTint: "light",
  isDark: false,
};
```

**The Problem:**

1. **Tab Bar Background:** In light theme, `colors.surface` = `#FFFFFF` (pure white)
2. **Tab Icons Default:** `tabIconDefault` = `#7A99BC` (light blue-gray)
3. **Tab Icons Selected:** `tabIconSelected` = `#0052CC` (dark blue)
4. **Device Navigation Bar (Android):** The system navigation bar (gesture bar / 3-button nav) is NOT being controlled by the app

When the device is in light mode:
- The Android system navigation bar background becomes **white** or **transparent**
- The tab bar icons (`#7A99BC`) have **insufficient contrast** against white
- The system navigation bar buttons (back/home/recents) are also white/light
- Result: **Everything blends into white and becomes invisible**

**Also in `ThemeContext.tsx`:**
```tsx
useEffect(() => {
  SystemUI.setBackgroundColorAsync(colors.background).catch(() => {});
}, [colors.background]);
```
This only sets the **system UI background** (behind the app), not the **navigation bar color**.

### ✅ Fix Solution: Control the Android Navigation Bar

**File to modify: `app/_layout.tsx`**

Add `expo-navigation-bar` or use `expo-system-ui` to control the navigation bar appearance. Since you already have `expo-system-ui` in dependencies, here's the fix:

```tsx
// app/_layout.tsx
import * as SystemUI from "expo-system-ui";
import * as NavigationBar from "expo-navigation-bar"; // Add this import
import { Platform } from "react-native";

// In ThemeProvider or RootLayout, add this effect:
useEffect(() => {
  // Set system UI background
  SystemUI.setBackgroundColorAsync(colors.background).catch(() => {});
  
  // FIX: Control Android navigation bar
  if (Platform.OS === "android") {
    NavigationBar.setBackgroundColorAsync(colors.surface).catch(() => {});
    NavigationBar.setButtonStyleAsync(colors.isDark ? "light" : "dark").catch(() => {});
    NavigationBar.setBorderColorAsync(colors.surfaceBorder).catch(() => {});
  }
}, [colors.background, colors.surface, colors.surfaceBorder, colors.isDark]);
```

**Alternative Fix (without adding new dependency):**

Use `StatusBar` from `expo-status-bar` with `translucent` and `backgroundColor` props, but the navigation bar still needs explicit control.

**Better Fix in `app/_layout.tsx`:**

### **Analysis of `app/my-qr-codes.tsx`**

#### **1. Firebase Subscription Costs (Real-time Listeners)**

```tsx

  if (unsubGroupsRef.current) { unsubGroupsRef.current(); unsubGroupsRef.current = null; }
```

**Cost Impact:**

### ✅ Cost Reduction Plan

#### **Phase 1: Reduce Firebase Reads (Immediate - High Impact)**

**1. Switch from Real-time to Fetch-on-Demand**

```tsx
// REPLACE in my-qr-codes.tsx

// ❌ CURRENT: Real-time listeners (expensive)
useEffect(() => {
  if (!user) return;
  unsubQrsRef.current = subscribeToUserGeneratedQrs(user.id, (items) => {
    setQrCodes(items);
  });
  unsubGroupsRef.current = subscribeToUserGroups(user.id, (gs) => {
    setGroups(gs);
  });
}, [user?.id]);

// ✅ FIX: Fetch once + manual refresh (cheaper)
useEffect(() => {
  if (!user) return;
  fetchQrCodes();
  fetchGroups();
}, [user?.id]);

async function fetchQrCodes() {
  if (!hasLoadedRef.current) setLoading(true);
  try {
    const items = await getUserGeneratedQrsOnce(user.id); // One-time fetch
    setQrCodes(items);
  } catch (e) {
    console.error(e);
  } finally {
    setLoading(false);
    hasLoadedRef.current = true;
  }
}

async function fetchGroups() {
  setGroupsLoading(true);
  try {
    const gs = await getUserGroupsOnce(user.id); // One-time fetch
    setGroups(gs);
  } catch (e) {
    console.error(e);
  } finally {
    setGroupsLoading(false);
  }
}

function handleRefresh() {
  setRefreshing(true);
  Promise.all([fetchQrCodes(), fetchGroups()]).finally(() => {
    setRefreshing(false);
  });
}
```

#### **Phase 4: Caching Strategy (Medium Impact)**

```tsx
// Add AsyncStorage caching for QR codes
import AsyncStorage from '@react-native-async-storage/async-storage';

const CACHE_KEY = (userId: string) => `qr_codes_${userId}`;
const CACHE_TTL = 5 * 60 * 1000; // 5 minutes

async function fetchWithCache(userId: string) {
  // Try cache first
  const cached = await AsyncStorage.getItem(CACHE_KEY(userId));
  if (cached) {
    const { data, timestamp } = JSON.parse(cached);
    if (Date.now() - timestamp < CACHE_TTL) {
      setQrCodes(data);
      setLoading(false);
      return;
    }
  }
  
  // Fetch fresh
  const items = await getUserGeneratedQrsOnce(userId);
  await AsyncStorage.setItem(CACHE_KEY(userId), JSON.stringify({
    data: items,
    timestamp: Date.now(),
  }));
  setQrCodes(items);
}
```
