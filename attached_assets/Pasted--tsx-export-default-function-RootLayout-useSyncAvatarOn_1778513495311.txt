## 🛡️ Edge Cases & Best Practices

| Scenario | Handling |
|----------|----------|
| **User updates photo on another device** | `useSyncAvatarOnMount` catches it on next app open. Add pull-to-refresh on Profile if needed. |
| **Upload fails** | `onError` rolls back to previous URL + version. UI never shows broken state. |
| **Offline mode** | `expo-image` serves disk cache. Fallback emoji if never loaded. |
| **Storage URL changes (migration)** | Version param forces fresh fetch. Old cache auto-evicts. |
| **Multiple avatars (team/business)** | Create `useAvatarStore(uid)` factory or key MMKV by `avatar_${uid}`. |
