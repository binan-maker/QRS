# 🔍 Home Page: Complete Performance, Cost & Architecture Analysis

Based on your Expo Router + Firebase stack and the symptoms you're experiencing (slow initial load, high Firestore reads, janky UI, heavy buttons/texts), here's a **production-grade, multi-file breakdown** of why the Home page is slow/expensive and exactly how to fix it.

---

## 📉 Root Cause Analysis: Why It's Slow & Expensive

| Symptom | Technical Root Cause | Impact |
|---------|----------------------|--------|
| **2-4s white screen on mount** | Waterfall `await` calls for user profile, stats, recent QRs, banners, security config | Blocks render until all resolve |
| **High Firestore cost** | `onSnapshot` on static-ish data + full document fetches | ~50-150 reads/tab switch |
| **Scroll/UI jank** | `FlatList` without virtualization, inline computations, un-memoized cards | Drops below 45 FPS on mid-tier devices |
| **Button lag** | Unstable references (`() => fn`), direct async writes on tap, no `disabled` state | Main thread blocked, double-tap bugs |
| **Text/Image layout shift** | Dynamic height calculations, uncached assets, synchronous date/URL formatting | CLS (Cumulative Layout Shift) > 0.15 |

### 2️⃣ `features/home/hooks/useHomeData.ts` (Data Layer)
**Current Problem:** Sequential promises, no caching, no field projection.

**✅ Fix: Parallel Fetch + React Query + Field Selection**
```typescript
import { useQuery } from '@tanstack/react-query';
import { collection, query, where, orderBy, limit, getDocs, doc, getDoc } from 'firebase/firestore';
import { db } from '@/lib/firebase';

async function fetchHomeData(uid: string) {
  // ✅ Run in parallel
  const [userSnap, statsSnap, recentQrsSnap] = await Promise.all([
    getDoc(doc(db, 'users', uid), { fields: ['displayName', 'avatarUrl', 'verified'] }),
    getDoc(doc(db, 'users', uid, 'stats', 'aggregate')),
    getDocs(query(
      collection(db, 'users', uid, 'history'),
      orderBy('scannedAt', 'desc'),
      limit(8)
    ))
  ]);

  return {
    user: userSnap.data(),
    stats: statsSnap.data(),
    recentQrs: recentQrsSnap.docs.map(d => ({
      id: d.id,
      ...d.data({ serverTimestamps: 'estimate' }),
      // ✅ Project only UI-needed fields
      content: d.data().content?.slice(0, 80),
      type: d.data().qrType,
      status: d.data().securityStatus || 'safe'
    }))
  };
}

export function useHomeData(uid: string) {
  return useQuery({
    queryKey: ['home', uid],
    queryFn: () => fetchHomeData(uid),
    staleTime: 1000 * 60 * 3,     // Cache 3 mins
    gcTime: 1000 * 60 * 15,       // Keep 15 mins
    refetchOnWindowFocus: false,
    refetchOnMount: false,
    placeholderData: keepPreviousData,
  });
}
```

## 💾 Caching Strategy: What to Cache vs What Not To

| Data Type | Cache? | Tool | TTL | Why |
|-----------|--------|------|-----|-----|
| **User profile & stats** | ✅ Yes | React Query | 3-5 min | Rarely changes, high read cost |
| **Recent QRs/History** | ✅ Yes | React Query + FlashList | 2 min | Append-only, safe to stale |
| **Security alerts/banners** | ⚠️ Partial | React Query | 10 min | Cache safe alerts, real-time only for critical |
| **App config/feature flags** | ✅ Yes | MMKV + React Query | 1 hour | Static, sync on app start |
| **QR/Avatar images** | ✅ Yes | `expo-image` memory-disk | Indefinite | Heavy network cost, zero reason to reload |
| **Button states (loading)** | ✅ Yes | Zustand/Context | Session | Prevents re-sync on tab switch |
| **Real-time scan velocity** | ❌ No | `onSnapshot` | Real-time only | Low volume, time-sensitive |

**Firestore Cost Rule:** `onSnapshot` charges **1 read per document** on attach + every doc change. For a home page with 15 items = 15 reads + continuous overhead. Replace with `getDocs` + `staleTime` + pull-to-refresh.

## 🖼️ UI/UX & Button/Text Optimization Checklist

### 🔘 Buttons (Scan, Generate, Share, Report, Quick Actions)
| Anti-Pattern | ✅ Fix |
|--------------|--------|
| `onPress={() => handleAction(id)}` | `useCallback` + stable reference |
| No `disabled` state during async | Add `isLoading` state, show spinner, `disabled={loading}` |
| `hitSlop` missing | Add `hitSlop={8}` to prevent mis-taps |
| Dynamic inline styles | Extract to `StyleSheet.create()` outside component |

### 📝 Text Rendering (Dates, URLs, Stats, Status)
| Anti-Pattern | ✅ Fix |
|--------------|--------|
| `new Date().toLocaleString()` in render | `useMemo` + `date-fns` or `dayjs` |
| Long URLs without truncation | `numberOfLines={1}` + `ellipsizeMode="tail"` |
| Dynamic height calculations | Fixed `minHeight` + `flex` layout |
| Re-computing trust scores | Memoize or pre-compute at fetch time |

### 📐 Layout & Scroll Performance
- Replace `<ScrollView>` with `<FlashList>` or `<FlatList>` + `removeClippedSubviews`
- Set `windowSize={5}` to limit off-screen renders
- Avoid `LayoutAnimation` on lists (causes jank on Android)
- Use `collapsable={false}` only when necessary (default `true` improves perf)
