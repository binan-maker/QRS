```text
navigation setup
```

Because:

So Expo warns you.

# HOW TO FIX

# BEST FIX → REMOVE THOSE CALLS

Search entire project for:

```tsx
setPositionAsync
setBackgroundColorAsync
setBorderColorAsync
```

# LIKELY FILES
