# 🔍 Profile Image Lifecycle: Storage Cleanup Analysis & Fix

Based on your QR Guard architecture (Expo + Firebase), here's the **critical truth** about what happens to images in Firebase Storage when users change or remove their profile photo.

---

## ⚠️ The Problem: Orphaned Files = Silent Cost Explosion

### What Likely Happens Now (Default Behavior)

| User Action | What Happens in Storage | What Happens in Firestore | Result |
|-------------|------------------------|---------------------------|--------|
| **Upload new image** | New file saved: `profile-photos/{uid}_new.jpeg` | `avatarUrl` updated to new URL | ✅ New image works |
| **Upload again** | Another new file saved: `profile-photos/{uid}_newer.jpeg` | `avatarUrl` updated again | ❌ Old file **orphaned** (never deleted) |
| **Remove image** | File **still exists** in Storage | `avatarUrl` set to `null` or Google photo | ❌ File **orphaned** + privacy risk |
| **Delete account** | Files **still exist** in Storage | User doc deleted | ❌ **Compliance violation** (GDPR/DPDP) |

### The Hidden Cost Math

```
Assumptions:
- 1,000 users upload profile photo 3x/year on average
- Avg image size: 150KB (compressed)
- No cleanup = orphaned files accumulate

Year 1: 1,000 users × 3 uploads × 150KB = ~450MB stored
Year 2: +450MB = 900MB stored
Year 3: +450MB = 1.35GB stored

Firebase Storage pricing: ~$0.026/GB/month
Year 3 monthly cost for orphans: 1.35GB × $0.026 = ~$0.035/month

Seems small? Scale to 10K users:
10K × 3 × 150KB × 3 years = 13.5GB → ~$0.35/month

BUT add:
- Network egress fees ($0.12/GB)
- Operation fees ($0.05/1K operations)
- Backup/replication overhead
- Compliance audit risk

Real impact: ~$2-5/month at 1K users, ~$20-50/month at 10K users
```

**Worse:** Orphaned files are **accessible via URL** if someone guesses the path. Privacy risk.

## ✅ The Correct Architecture: Automatic Cleanup on Change/Delete

### Flow Diagram
```
User Changes Image
        │
        ▼
[Frontend] Upload new image → Get new URL
        │
        ▼
[Frontend] Read current avatarUrl from Firestore
        │
        ▼
[Cloud Function] Trigger: onUpdate users/{uid}
        │
        ├─► If avatarUrl changed:
        │   │
        │   ▼
        │   [Storage] Delete old file (if exists & owned by user)
        │   │
        │   ▼
        │   [Firestore] Update avatarUrl + avatarVersion
        │
        ▼
[Frontend] Show new image instantly (optimistic UI)
```

## 🛠️ Implementation: Auto-Cleanup Cloud Function

### Step 1: Cloud Function Trigger on User Update
```typescript
// functions/src/cleanupProfileImage.ts
import * as functions from 'firebase-functions';
import * as admin from 'firebase-admin';
import { Storage } from '@google-cloud/storage';

admin.initializeApp();
const storage = new Storage(); // Firebase Storage admin client
const BUCKET_NAME = 'your-app.appspot.com'; // Replace with your bucket

export const cleanupProfileImage = functions.firestore
  .document('users/{uid}')
  .onUpdate(async (change, context) => {
    const uid = context.params.uid;
    const before = change.before.data();
    const after = change.after.data();

    const oldAvatar = before?.avatarUrl;
    const newAvatar = after?.avatarUrl;

    // ✅ Only cleanup if avatar changed AND new value is different
    if (!oldAvatar || oldAvatar === newAvatar) {
      return null;
    }

    // ✅ Extract file path from URL
    // Format: https://firebasestorage.googleapis.com/v0/b/.../profile-photos/{uid}_xxx.jpeg
    try {
      const url = new URL(oldAvatar);
      const pathRegex = /\/o\/(.+?)\?/;
      const match = url.pathname.match(pathRegex);
      
      if (!match?.[1]) {
        console.warn('Could not parse old avatar URL:', oldAvatar);
        return null;
      }

      const filePath = decodeURIComponent(match[1]);
      
      // ✅ Security check: Ensure file belongs to this user
      if (!filePath.includes(`profile-photos/${uid}`)) {
        console.warn('Suspicious avatar path mismatch:', { uid, filePath });
        return null;
      }

      // ✅ Delete from Storage
      const file = storage.bucket(BUCKET_NAME).file(filePath);
      const [exists] = await file.exists();
      
      if (exists) {
        await file.delete();
        console.log(`✅ Cleaned up orphaned avatar: ${filePath}`);
      }
    } catch (error) {
      console.error('Avatar cleanup failed:', error);
      // Don't throw - don't block user update if cleanup fails
    }

    return null;
  });
```

### Step 2: Handle Account Deletion (GDPR/DPDP Compliance)
```typescript
// functions/src/cleanupUserData.ts
export const cleanupUserData = functions.auth.user().onDelete(async (user) => {
  const uid = user.uid;

  // 1️⃣ Delete profile photo
  try {
    const [files] = await storage
      .bucket(BUCKET_NAME)
      .getFiles({ prefix: `profile-photos/${uid}/` });
    
    for (const file of files) {
      await file.delete();
    }
    console.log(`✅ Deleted profile photos for ${uid}`);
  } catch (err) {
    console.error('Profile photo cleanup failed:', err);
  }

  // 2️⃣ Delete generated QR images
  try {
    const [qrFiles] = await storage
      .bucket(BUCKET_NAME)
      .getFiles({ prefix: `qr-images/${uid}/` });
    
    for (const file of qrFiles) {
      await file.delete();
    }
    console.log(`✅ Deleted QR images for ${uid}`);
  } catch (err) {
    console.error('QR image cleanup failed:', err);
  }

  // 3️⃣ Delete Firestore docs (if not already handled)
  await admin.firestore().collection('users').doc(uid).delete();
  
  console.log(`✅ Full cleanup completed for ${uid}`);
  return null;
});
```

### Step 3: Frontend Upload Hook with Optimistic UI + Versioning
```typescript
// lib/hooks/useUpdateAvatar.ts
import { useMutation, useQueryClient } from '@tanstack/react-query';
import { doc, updateDoc, getDoc } from 'firebase/firestore';
import { auth, db } from '@/lib/firebase';
import { useAvatarStore } from '@/lib/store/avatarStore';
import { uploadProfilePhoto } from '@/lib/services/storage-service';

export function useUpdateAvatar() {
  const queryClient = useQueryClient();
  const { setAvatar, url: prevUrl, version: prevVersion } = useAvatarStore();

  return useMutation({
    mutationFn: async (localUri: string) => {
      const result = await uploadProfilePhoto(localUri);
      if (!result.success) throw new Error(result.error || 'Upload failed');
      return result.url;
    },
    
    onMutate: async (localUri) => {
      // ✅ INSTANT UI: Show local file immediately
      const tempVersion = Date.now();
      setAvatar(localUri, tempVersion);
      
      // Snapshot previous for rollback
      const uid = auth.currentUser?.uid;
      if (!uid) return;
      
      const prevData = queryClient.getQueryData(['profile', uid]);
      return { prevData, prevUrl, prevVersion };
    },
    
    onSuccess: async (downloadUrl) => {
      const uid = auth.currentUser?.uid;
      if (!uid) return;
      
      // ✅ Swap to CDN URL + new version (triggers cache bust)
      const newVersion = Date.now();
      setAvatar(downloadUrl, newVersion);
      
      // ✅ Update Firestore (triggers Cloud Function cleanup)
      await updateDoc(doc(db, 'users', uid), {
        avatarUrl: downloadUrl,
        avatarVersion: newVersion,
        updatedAt: admin.firestore.FieldValue.serverTimestamp()
      });
      
      // ✅ Invalidate profile cache to refresh UI
      queryClient.invalidateQueries({ queryKey: ['profile', uid] });
    },
    
    onError: (_, __, context) => {
      // 🔄 Rollback to previous on failure
      if (context?.prevUrl) {
        setAvatar(context.prevUrl, context.prevVersion);
      }
    }
  });
}
```

### Step 4: Handle "Remove Image" Action
```typescript
// In profile settings: "Remove Profile Photo" button

    // ✅ Update Firestore (triggers cleanup Cloud Function)
    await updateDoc(doc(db, 'users', uid), {
      avatarUrl: null,
      avatarVersion: Date.now(), // Force cache bust
      updatedAt: admin.firestore.FieldValue.serverTimestamp()
    });

    // ✅ Clear cache
    queryClient.invalidateQueries({ queryKey: ['profile', uid] });
    showToast('Profile photo removed', 'checkmark-circle');
  } catch (err) {
    // Rollback on error
    useAvatarStore.getState().setAvatar(prevUrl, prevVersion);
    showToast('Failed to remove photo', 'alert-circle');
  }
};
```

## 🔐 Security & Compliance Checklist

| Requirement | Implementation |
|-------------|---------------|
| **Only delete user-owned files** | Path validation: `filePath.includes(profile-photos/${uid})` |
| **Never block user update if cleanup fails** | `try/catch` + log error, don't throw |
| **GDPR/DPDP "Right to Erasure"** | `cleanupUserData` function deletes all user files on account deletion |
| **Prevent URL guessing attacks** | Use unpredictable filenames: `${uid}_${timestamp}_${random}.jpeg` |
| **Cache busting after change** | Append `?v=${avatarVersion}` to URL in `SmartAvatar` |
| **Audit logging** | Log all deletions: `console.log('✅ Cleaned up: ${filePath}')` |

# 🚀 Profile Image Upload UX + Modal Animation Fix

## ✅ Fix 1: Show Profile Image Immediately (No Loading Spinner)

### The Problem
Current flow: User picks image → Shows loading spinner → Uploads → Updates UI.  
This creates **perceived latency** and reduces trust ("Is it working?").

### The Solution: Optimistic UI with Background Upload
Show the selected image **instantly** using the local URI, then upload in the background. Only show a subtle progress indicator if needed—not on the avatar itself.

```tsx
// features/profile/components/ProfileImageUploader.tsx
import { useState, useCallback } from 'react';
import { View, TouchableOpacity, StyleSheet, Platform } from 'react-native';
import * as ImagePicker from 'expo-image-picker';
import { Image } from 'expo-image';
import { useUpdateAvatar } from '@/lib/hooks/useUpdateAvatar';
import { Ionicons } from '@expo/vector-icons';

export function ProfileImageUploader({ currentAvatar, userId }: { currentAvatar?: string; userId: string }) {
  const [previewUri, setPreviewUri] = useState<string | null>(null);
  const { mutate: updateAvatar, isPending } = useUpdateAvatar();

  const pickImage = useCallback(async () => {
    const result = await ImagePicker.launchImageLibraryAsync({
      mediaTypes: ImagePicker.MediaTypeOptions.Images,
      allowsEditing: true,
      aspect: [1, 1],
      quality: 0.8,
    });

    if (!result.canceled && result.assets?.[0]?.uri) {
      const localUri = result.assets[0].uri;
      
      // ✅ INSTANT UI: Show local image immediately
      setPreviewUri(localUri);
      
      // ✅ Background upload: No blocking, no spinner on avatar
      updateAvatar(localUri, {
        onSuccess: (downloadUrl) => {
          // Upload succeeded: previewUri already shows, cache will update
          setPreviewUri(null); // Let CachedAvatar take over with CDN URL
        },
        onError: () => {
          // Upload failed: revert to previous
          setPreviewUri(null);
        }
      });
    }
  }, [updateAvatar]);

  // ✅ Determine which image to show: Preview > Current Avatar > Fallback
  const displayUri = previewUri || currentAvatar;

  return (
    <View style={styles.container}>
      <TouchableOpacity onPress={pickImage} style={styles.avatarWrapper} activeOpacity={0.8}>
        {displayUri ? (
          <Image
            source={{ uri: displayUri }}
            style={styles.avatar}
            cachePolicy={previewUri ? 'none' : 'memory-disk'} // ✅ Don't cache temp preview
            contentFit="cover"
            transition={previewUri ? 0 : 200} // ✅ Instant for preview, smooth for CDN
          />
        ) : (
          <View style={[styles.avatar, styles.fallback]}>
            <Ionicons name="person" size={32} color="#94a3b8" />
          </View>
        )}
        
        {/* ✅ Subtle edit indicator (not a blocking spinner) */}
        <View style={styles.editBadge}>
          <Ionicons name="camera" size={14} color="#ffffff" />
        </View>
      </TouchableOpacity>
      
      {/* ✅ Optional: Non-blocking progress bar below avatar */}
      {isPending && (
        <View style={styles.progressContainer}>
          <View style={styles.progressBar}>
            <View style={styles.progressFill} />
          </View>
          <Text style={styles.progressText}>Uploading...</Text>
        </View>
      )}
    </View>
  );
}

const styles = StyleSheet.create({
  container: { alignItems: 'center', marginBottom: 16 },
  avatarWrapper: { position: 'relative' },
  avatar: { width: 96, height: 96, borderRadius: 48, backgroundColor: '#f1f5f9' },
  fallback: { justifyContent: 'center', alignItems: 'center', backgroundColor: '#e2e8f0' },
  editBadge: {
    position: 'absolute',
    bottom: 4,
    right: 4,
    backgroundColor: '#3b82f6',
    borderRadius: 12,
    padding: 6,
    borderWidth: 2,
    borderColor: '#ffffff'
  },
  progressContainer: { marginTop: 12, alignItems: 'center', width: '100%' },
  progressBar: {
    height: 4,
    backgroundColor: '#e2e8f0',
    borderRadius: 2,
    width: '60%',
    overflow: 'hidden'
  },
  progressFill: {
    height: '100%',
    backgroundColor: '#3b82f6',
    width: '60%', // Could animate this with real progress
    borderRadius: 2
  },
  progressText: {
    fontSize: 11,
    color: '#64748b',
    marginTop: 4
  }
});
```

**Key UX Wins:**
- ✅ **Zero perceived wait**: Image appears the moment user confirms selection
- ✅ **Trust signal**: App feels responsive and confident
- ✅ **Non-blocking feedback**: Subtle progress bar below, not on the avatar
- ✅ **Smooth transition**: `transition={0}` for instant preview, `200` for CDN swap

## ✅ Fix 2: Modal Fade Animation + Dark Backdrop

### The Problem
Current modal: Pops in without animation, backdrop is transparent → feels cheap, distracts from content.

### The Solution: Fade In/Out + Semi-Transparent Black Backdrop
Use `react-native-reanimated` for smooth fades and a proper dimmed backdrop.

```tsx
// components/ui/FadeModal.tsx (Updated with Backdrop)
import React, { useEffect } from 'react';
import { Modal, View, TouchableOpacity, StyleSheet, Platform } from 'react-native';
import Animated, {
  useSharedValue,
  useAnimatedStyle,
  withTiming,
  Easing,
  FadeIn,
  FadeOut,
} from 'react-native-reanimated';

interface FadeModalProps {
  visible: boolean;
  onClose: () => void;
  children: React.ReactNode;
  position?: 'center' | 'bottom' | 'top';
}

export const FadeModal: React.FC<FadeModalProps> = ({
  visible,
  onClose,
  children,
  position = 'center',
}) => {
  const opacity = useSharedValue(0);
  const scale = useSharedValue(0.95);

  useEffect(() => {
    if (visible) {
      // ✅ Fade in + slight scale up
      opacity.value = withTiming(1, { duration: 200, easing: Easing.out(Easing.ease) });
      scale.value = withTiming(1, { duration: 200, easing: Easing.out(Easing.ease) });
    } else {
      // ✅ Fade out + slight scale down
      opacity.value = withTiming(0, { duration: 150, easing: Easing.in(Easing.ease) });
      scale.value = withTiming(0.95, { duration: 150, easing: Easing.in(Easing.ease) });
    }
  }, [visible]);

  const animatedStyle = useAnimatedStyle(() => ({
    opacity: opacity.value,
    transform: [{ scale: scale.value }],
  }));

  const getPositionStyle = () => {
    switch (position) {
      case 'bottom':
        return { bottom: 0, left: 0, right: 0 };
      case 'top':
        return { top: Platform.OS === 'ios' ? 50 : 30, left: 16, right: 16 };
      case 'center':
      default:
        return { top: '30%', left: 16, right: 16 };
    }
  };

  return (
    <Modal
      visible={visible}
      transparent={true}
      animationType="none" // ✅ Disable default slide
      onRequestClose={onClose}
    >
      {/* ✅ Dark semi-transparent backdrop */}
      <TouchableOpacity
        style={styles.backdrop}
        activeOpacity={1}
        onPress={onClose}
      >
        <Animated.View
          entering={FadeIn.duration(200)}
          exiting={FadeOut.duration(150)}
          style={[styles.backdropOverlay, { backgroundColor: 'rgba(0, 0, 0, 0.5)' }]} // ✅ Black with 50% opacity
        />
      </TouchableOpacity>

      {/* ✅ Modal content with fade+scale animation */}
      <View style={[styles.contentContainer, getPositionStyle()]}>
        <Animated.View style={[styles.content, animatedStyle]}>
          {children}
        </Animated.View>
      </View>
    </Modal>
  );
};

const styles = StyleSheet.create({
  backdrop: {
    ...StyleSheet.absoluteFillObject,
    justifyContent: 'center',
    alignItems: 'center',
  },
  backdropOverlay: {
    ...StyleSheet.absoluteFillObject,
  },
  contentContainer: {
    position: 'absolute',
  },
  content: {
    backgroundColor: '#ffffff',
    borderRadius: 16,
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 4 },
    shadowOpacity: 0.3,
    shadowRadius: 12,
    elevation: 8,
    overflow: 'hidden',
  },
});

export default FadeModal;
```
